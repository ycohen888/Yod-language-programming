בניית שפת יוד מאפס ב־Go

יוד — שפת תכנות מלאה בעברית לפיתוח תוכנות Windows. השם מהאות י׳: סמל לחכמה ביהדות. כך דובר עברית יוכל לכתוב קוד, להבין שגיאות, להשתמש בספריות ולפתח בלי ללמוד אנגלית. המימוש מאחורי הקלעים ב־Go: מפרש/VM משלנו, לא המרה למילות מפתח באנגלית ולא קומפיילר לקוד מכונה בשלב הראשון.

שם: יוד (Yod) מימוש: Go מודל: Interpreter → Bytecode VM יעד: Windows סגנון: PHP-like + OOP ספריות: רשת · SQL · GUI סיומת: .יוד

מה אנחנו עושים

המטרה: ליצור את שפת יוד — שפת עבודה בעברית עם מילות מפתח, ספריות, שגיאות ותיעוד בעברית — ועם יכולת לבנות אפליקציות Windows אמיתיות, רשת, SQL, קבצים ומחלקות.

כן — מה כן בונים

Lexer, Parser, AST, Interpreter/VM, מערכת מודולים (`כלול`), מחלקות, ספריות מובנות, CLI להרצה, ובהמשך עורך RTL.

לא — מה לא עושים בהתחלה

לא מחליפים `אם` ל־`if` ומריצים בשפה זרה. לא בונים קומפיילר native/אסמבלר בשלב הראשון. לא תלויים ב־Visual Studio.

זרימת העבודה

קובץ.יוד → מקמפל יוד (Go): Lexer → Parser → AST → Interpreter / Bytecode VM → ספריות בעברית (בסיס, קבצים, רשת, SQL, חלונות, ציור, הצפנה, לוח) → Windows APIs דרך ה־runtime

אתה מתקין Go ומקמפל את הפרויקט (`go build`). אנחנו כותבים את המנוע בהדרגה לפי השלבים למטה.

ארכיטקטורה

שכבות המנוע

token → lexer → ast → parser → object → evaluator / vm → stdlib

מודל הרצה

שלב א׳: Tree-walk interpreter על AST. שלב ב׳: קומפילציה ל־bytecode פנימי + VM שלנו (עדיין לא machine code).

SQL

ספריית SQL דרך כלול "SQL". חיבור למסד, הרצת שאילתות, קבלת תוצאות כרשימות/מילונים בעברית. התחלה עם SQLite (מובנה לקובץ), ואחר כך מחברים לשרתים חיצוניים.

ניהול זיכרון

כל ערכי השפה הם אובייקטי heap ב־Go (object.Object). מחלקות, רשימות ומילונים מועברים בהפניה (שינוי דרך משתנה אחד נראה באחר). מספרים/מחרוזות/בוליאנים הם בלתי־משתנים. איסוף זבל: GC של Go. משאבים חיצוניים (חיבור SQL וכו׳) — סגירה מפורשת (סגור). סגירות תופסות משתנים חיצוניים (גם ב־VM מ־0.22.0).

כיוון API ל־SQL

כלול "SQL" משתנה מסד = SQL.התחבר("sqlite", "נתונים.db") מסד.הפעל("CREATE TABLE IF NOT EXISTS משתמשים (מזהה INTEGER, שם TEXT)") מסד.הפעל("INSERT INTO משתמשים VALUES (?, ?)", 1, "נועם") משתנה שורות = מסד.שלוף("SELECT * FROM משתמשים") עבור שורה בתוך שורות { הדפס(שורה["שם"]) }
שאילתות עם פרמטרים (?) חובה מהיום הראשון — כדי למנוע SQL Injection גם כשהשפה נוחה למתחילים.
