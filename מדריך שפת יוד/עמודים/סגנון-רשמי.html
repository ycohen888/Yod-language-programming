סגנון רשמי יוד

הסגנון המומלץ הוא כמו PHP: סוגריים לפרמטרים ותנאים, וסוגריים מסולסלים לבלוקים. הכלי יוד סדר / Shift+Alt+F ממיר קוד ישן (עם סוף) לסגנון זה.

בלוקים ופונקציות

כתבו פונקציה שם(פרמטרים) { … }, אם (תנאי) { … } אחרת { … }, ו־כל_עוד (תנאי) { … }. מילת סוף עדיין נתמכת לתאימות לאחור, אבל אינה הסגנון המומלץ. מילון נשאר: { "מפתח": ערך }.

קריאות

שני הסגנונות חוקיים: שם(א, ב) ו־שם: א, ב. הסגנון המומלץ לקריאות הוא עם סוגריים, כמו PHP.

מינוס

כתבו -1 ו־-x במפורש. לחיסור השאירו רווחים: א - ב. בארגומנט שלילי: פונ(-1).

בדיקת סגנון

יוד בדוק מדווח על שגיאות תחביר ועל מינוס צמוד אחרי מזהה. יוד סדר מסדר הזחות ומעביר ל־() / {}.
