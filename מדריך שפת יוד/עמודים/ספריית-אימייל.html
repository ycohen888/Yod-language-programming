ספריית אימייל

שליחת SMTP (כולל Gmail), גוף HTML, קריאת IMAP, ו־OAuth ל־Gmail. טוענים עם כלול "אימייל".

Gmail OAuth

ב־Google Cloud Console צרו OAuth Client (Desktop/Web) עם redirect http://127.0.0.1:8765/oauth2callback. שמרו GMAIL_CLIENT_ID ו־GMAIL_CLIENT_SECRET בסביבה. 

אימייל.גימייל_oauth_התחבר({
  מזהה_לקוח: מערכת.סביבה("GMAIL_CLIENT_ID"),
  סוד: מערכת.סביבה("GMAIL_CLIENT_SECRET"),
  קובץ_טוקן: "gmail-token.json"
})

אימייל.גימייל({
  משתמש: מערכת.סביבה("GMAIL_USER"),
  oauth_טוקן: "gmail-token.json",
  אל: "a@b.com",
  נושא: "שלום",
  תוכן_HTML: "
ללא סיסמת אפליקציה
"
})

שליחה ברקע (בלי מסך שחור · 0.99.0)

שליחת SMTP חוסמת עד שהשרת מגיב (שניות). מתוך לחיצה/טיימר בממשק זה תוקע את המסך. הדפוס הלא-חוסם: שלח_התחל/גימייל_התחל מתחיל את השליחה ברקע ומחזיר {מזהה}, ואז מבצעים פוללינג עם טיימרים.אחרי על מצב_שליחה. 

כלול "אימייל"
כלול "טיימרים"

משתנה שליחה = אימייל.גימייל_התחל({
  משתמש: מערכת.סביבה("GMAIL_USER"),
  סיסמה: מערכת.סביבה("GMAIL_APP_PASS"),
  אל: "a@b.com",
  נושא: "התראה",
  תוכן_HTML: "שלום"
})
פונקציה בדוק()
  משתנה מצב = אימייל.מצב_שליחה(שליחה.מזהה)
  אם (לא מצב.הסתיים) {
    טיימרים.אחרי(200, בדוק)
    החזר ריק
  }
  אם (מצב.הצליח) { הדפס "נשלח" } אחרת { הדפס "נכשל: " + מצב.שגיאה }
