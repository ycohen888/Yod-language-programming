# מנהל מטלות — דוגמה פתוחת קוד ביוד

אפליקציית שולחן עבודה קטנה בעברית לניהול מטלות, שכל הקוד שלה **פתוח ומשוחרר לגיט** כדוגמה לימודית. כולה נכתבה בשפת **יוד**, מבוססת על **ספריית העיצוב** (`עיצוב/`, ממשק ב־WebView2 עם Bootstrap ו־Tabulator) ועל אחסון מקומי ב־**SQLite**.

בניגוד לתוכנות המוגמרות (מוניטור / גיבוי) שמופצות כקובץ הרצה בלבד — כאן **כל הקוד גלוי** כדי ללמוד ממנו.

## מה יש בתוכנה

- הוספת מטלה עם כותרת ובחירת עדיפות (גבוהה / רגילה / נמוכה).
- טבלה חכמה (`רשת_נתונים`) עם:
  - עמודת «בוצע» לסימון מהיר (מסמן את השורה בירוק עם קו חוצה).
  - עריכה ישירה (inline) של כותרת המטלה ושל העדיפות.
  - תגי עדיפות צבעוניים ומיון/סינון.
  - תפריט הקשר (קליק ימני) למחיקת שורה, ובחירה מרובה.
- פוטר קבוע: מונה «X מתוך Y הושלמו», ומתחתיו **בשורה אחת** פס התקדמות + «מחק שהושלמו» + «נקה הכול».
- שורת הוספה קומפקטית: **מה צריך | עדיפות | הוסף** בגובה אחיד.
- חלון בגודל קבוע (~720×560) שמתאים לפקדים — לא רוחב מסך מלא.
- מתג נושא כהה / בהיר בסרגל העליון.
- שמירה אוטומטית ב־SQLite — המטלות נשמרות בין הרצות.

## מבנה הקוד

| קובץ | תפקיד |
|------|--------|
| `התחל.יוד` | נקודת הכניסה (F5) — מייבאת ומריצה את `הפעל_מטלות` |
| `הפעלה.יוד` | טעינת מודולים, פתיחת המסד ובניית החלון |
| `מסד.יוד` | שכבת הנתונים — SQLite עם שאילתות מפורמטרות (`?`) |
| `ממשק.יוד` | בניית הממשק (סרגל, כרטיס הוספה, רשת נתונים, פוטר) + מטפלי האירועים |
| `לוגו.png` / `app.ico` | לוגו ואייקון חלון (גם ב־`נכסים/`) |

הנתונים נשמרים ב־`נתונים/מטלות.db` (התיקייה נוצרת אוטומטית ואינה עולה לגיט).

## איך מריצים

צריך את מנוע יוד (`yod.exe`) ואת תיקיית `עיצוב/` הסמוכה (נמצאת באותו ריפו, תחת `פרוייקט דוגמה/עיצוב/`).

**מהעורך:** פתחו את התיקייה `מטלות` בעורך יוד ולחצו F5.

**משורת הפקודה:**

```
yod.exe הרץ "פרוייקט דוגמה\מטלות"
```

## נקודות עניין ללומדים

- **הגנה מפני SQL injection** — כל הערכים מוזרקים דרך פרמטרים `?` (ראו `מסד.יוד`).
- **גשר JS ↔ יוד** — אירועי הטבלה (עריכה, מחיקה, בחירה) חוזרים לקוד יוד דרך ספריית העיצוב.
- **עיצוב מותנה** — שורות שהושלמו מקבלות מחלקת CSS (`yod-row-done`) המוגדרת ב־`עיצוב/ערכות.css`.
