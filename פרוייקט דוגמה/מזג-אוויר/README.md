# מזג־אוויר — דוגמה פתוחת קוד ביוד

חלון Windows **רגיל** (עם כותרת) + ממשק מזג־אוויר ב־WebView2.

## הרצה

```
yod.exe הרץ "פרוייקט דוגמה\מזג-אוויר"
```

או פתחו את התיקייה בעורך יוד ← F5 (נדרשת רשת).

## מה יש

- טמפרטורה, רוח, לחות, גשם, מינ׳/מקס׳
- תחזית שעתית + זריחה/שקיעה
- הגדרות: עיר בישראל, צלסיוס/פרנהייט, תמיד מעל, רענון
- נתונים מ־Open-Meteo

## שימוש

- ⚙ הגדרות · לחצן ימני לתפריט · סגירה בכותרת Windows
