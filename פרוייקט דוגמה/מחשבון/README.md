# מחשבון — דוגמה פתוחת קוד ביוד

מחשבון שולחן־עבודה מקצועי בעברית, כולו **קוד פתוח** ללימוד. החלון נבנה ב־**יוד** (`חלונות` + WebView2), והממשק הוא HTML/CSS/JS מקומיים עם עיצוב כהה/בהיר.

## מה יש בתוכנה

- תצוגה כפולה: ביטוי למעלה + תוצאה גדולה
- פעולות בסיס: `+ − × ÷` ואחוזים
- פונקציות: `√` · `x²` · `¹⁄ₓ` · `±`
- `C` / `CE` / `⌫`
- היסטוריית חישובים (לחיצה מחזירה תוצאה)
- מתג נושא כהה / בהיר
- תמיכה מלאה במקלדת (`0–9`, אופרטורים, Enter, Backspace, Esc)

## מבנה הקוד

| קובץ | תפקיד |
|------|--------|
| `התחל.יוד` | נקודת כניסה (F5) |
| `הפעלה.יוד` | אתחול תיקיית הרצה ופתיחת החלון |
| `ממשק.יוד` | חלון יוד + דפדפן שטוען `ממשק.html` |
| `ממשק.html` | מבנה הממשק |
| `סגנון.css` | עיצוב מקצועי (כהה/בהיר) |
| `מנוע.js` | לוגיקת החישוב, היסטוריה ומקלדת |
| `לוגו.png` / `app.ico` | לוגו ואייקון חלון |

## איך מריצים

צריך את מנוע יוד (`yod.exe`).

**מהעורך:** פתחו את התיקייה `מחשבון` בעורך יוד ולחצו F5.

**משורת הפקודה:**

```
yod.exe הרץ "פרוייקט דוגמה\מחשבון"
```

## נקודות עניין ללומדים

- **WebView מקומי** — `דפדפן.נווט` ל־`file:///` עם נכסי HTML/CSS/JS ליד הקוד.
- **הפרדת אחריות** — יוד מנהל חלון; הממשק והחישוב רצים בדפדפן (תגובה מיידית ללחיצות).
- **עיצוב** — משתני CSS, אנימציות עדינות, ורשת מקשים בסגנון מחשבון מודרני.
