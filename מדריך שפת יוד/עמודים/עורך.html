עורך יוד (IDE)

מגרסה 0.77 העורך הוא יוד IDE בלבד — Electron + React + CodeMirror 6, בסגנון Visual Studio Code: סייר, טאבים, פלטת פקודות, מינימפה, פאנל בעיות/פלט, והרצה דרך yod.exe. אין עורך Win32 מובנה.

הפעלה

yod
yod עורך
yod עורך נתיב\לפרויקט

בהפצה: ליד yod.exe נמצאת אפליקציה עצמאית Yod IDE.exe (בלי Node אצל המשתמש). אפשר גם ללחוץ ישירות על Yod IDE.exe.

בנייה מקומית של האפליקציה הארוזה (למפתחים):

cd yod-ide
npm install
npm run dist

או מצב פיתוח בלבד (npm run build) — Electron מתוך node_modules.

מדריך בתוך העורך

תפריט עזרה ← מדריך… פותח את המדריך בחלון נפרד של העורך (לא בדפדפן החיצוני). בחבילת ההפצה התיקייה מדריך שפת יוד נמצאת ליד yod.exe.

הגדרות והעדפות

תצוגה ← הגדרות… (או Ctrl+,) פותח מסך העדפות שנשמר אוטומטית לכל המחשב. כל שינוי מוחל בזמן אמת:

  • נושא — כהה / בהיר / ניגודיות גבוהה (משפיע על כל העורך ועל צבעי הקוד).
  • משפחת גופן וגודל גופן לעורך.
  • גודל טאב (רוחב הזחה) וגלישת שורות.
  • שמירה אוטומטית — שומר קבצים עם נתיב שנייה אחרי הפסקת ההקלדה.
  • סידור קוד בשמירה — מסדר קבצי יוד אוטומטית בכל שמירה.

נושאים (Themes)

שלוש ערכות: כהה (ברירת מחדל), בהיר, וניגודיות גבוהה. החלפת נושא מיידית — כולל צבעי הדגשת התחביר — בלי לאבד את מיקום הסמן, ההיסטוריה (בטל/בצע שוב) או הגלילה.

השוואה (Diff)

תצוגה ← «השוואה מול הדיסק…» פותחת תצוגה זה־לצד־זה בין תוכן העורך הנוכחי (כולל שינויים לא־שמורים) לבין הגרסה שעל הדיסק. הצד של העורך ניתן לעריכה, וליד כל הבדל יש כפתור מיזוג/החזרה להחזרת אותו קטע לגרסת הדיסק. «החל שינויים» מחזיר את התוצאה הערוכה לעורך. זמין רק לקובץ שמור, ומודיע אם אין הבדלים.

עריכה חכמה

  • קטעי קוד (Snippets) בעברית — הקלד פונקציה, מחלקה, אם, עבור, כל_עוד, נסה, בחר ועוד, ובחר את התבנית מרשימת ההשלמה. התבנית נפתחת מלאה, ו-Tab קופץ בין השדות (שם, פרמטרים, תנאי…). Esc יוצא.
  • קיפול קוד (Code folding) — כיווץ/הרחבה של בלוקים ({ } או פותח…סוף) בעזרת הסימון בשוליים, או Ctrl+Alt+[ (כווץ) / Ctrl+Alt+] (הרחב). בתפריט «קוד» יש גם «כווץ הכל» ו«הרחב הכל».
  • ריבוי סמנים (Multiple cursors) — Alt+לחיצה מוסיף סמן במקום נוסף; Ctrl+D בוחר את המופע הבא של המילה המסומנת (עריכה של כמה מקומות בבת אחת).
  • סגירת סוגריים והזחה חכמה — הקלדת (, [, { או מרכאות סוגרת אוטומטית; Enter אחרי פותח בלוק מזיח שורה פנימה, והקלדת סוף/} מיישרת את השורה החוצה.

טרמינל משולב והרצה

בפאנל התחתון יש לשונית «טרמינל» (Ctrl+`) — טרמינל אמיתי מבוסס xterm.js עם מעטפת PowerShell או CMD. אפשר לפתוח כמה סשנים (כפתור +, והחץ לידו לבחירת מעטפת), לעבור ביניהם בלשוניות, ולסגור כל אחד. הנושא והגופן של הטרמינל נגזרים מהגדרות העורך.

  • הרצה מפעילה את התוכנית — F5/F6 וכן «הרץ קובץ נוכחי» מריצים דרך מנוע יוד: חלון הקונסול מוסתר, וחלון התוכנה עצמה (GUI של «חלונות») עולה. פלט ושגיאות מופיעים בפאנל «פלט».
  • הרצה בתוך הטרמינל המשולב — Shift+F5 (או תפריט «הרצה ← הרץ בטרמינל המשולב») מריץ את התוכנית בתוך לשונית הטרמינל, למי שמעדיף פלט/קלט בתוך העורך.
  • הרץ קובץ נוכחי — מריץ את הקובץ הפעיל (לא רק התחל.יוד).
  • סרגל הרצה בסרגל הצד: הרץ ▶ · הרץ קובץ נוכחי · עצור (■, שולח Ctrl+C לטרמינל) · טרמינל · בדיקה · ארוז.
  • «בדוק» ו«ארוז» ממשיכים לרוץ בפאנל הפלט עם ניתוח שגיאות ללשונית «בעיות».

הערה: בסביבה ללא כלי בנייה של C++ ו־PTY נייטיב, הטרמינל פועל מעל צינורות (pipes) עם echo מקומי — הרצת פקודות וקלט־שורה עובדים היטב, אך תכונות TUI מלאות (עריכת שורה מתקדמת, היסטוריית חיצים ב־PowerShell) מוגבלות.

ביצועים

  • טעינת קבצים אסינכרונית (main process)
  • מעבר טאבים = מצב CodeMirror נפרד לכל קובץ (בלי טעינה מחדש מהדיסק)
  • הדגשת תחביר בעברית (RTL) ב־CodeMirror

אם העורך לא נפתח

בלי Yod IDE.exe ארוז וללא build פיתוח, yod עורך מדפיס הודעה בעברית עם פקודות ההתקנה — ולא נופל לעורך ישן.
