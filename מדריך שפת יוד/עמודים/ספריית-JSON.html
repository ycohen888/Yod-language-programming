ספריית JSON

המרה בין מחרוזת JSON לערכי יוד (מילון, רשימה, מספר, מחרוזת, בוליאני, ריק) ובחזרה. חובה לטעון עם כלול "JSON".

פרסור

המרה למחרוזת

טיפ: אובייקט JSON הופך למילון יוד; מערך JSON הופך לרשימה. אפשר לגשת לשדות עם נקודה: נתונים.שם.
שים לב: בתוך מחרוזת יוד, מרכאות JSON דורשות בריחה: "{\"מפתח\":1}". אפשר גם לקרוא קובץ עם קבצים.קרא ואז לפרסר.
ייפוי: JSON.מחרוזת(ערך, אמת) מחזיר JSON קריא עם שורות והזחות.
