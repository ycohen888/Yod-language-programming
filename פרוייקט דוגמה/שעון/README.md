# שעון — דוגמה פתוחת קוד ביוד

שעון שולחן־עבודה דיגיטלי בלי מסגרת Windows, עם כמה עיצובים.
כולו **קוד פתוח** ללימוד: חלון יוד + WebView2 + HTML/CSS/JS.

## מה יש

- 4 עיצובים: ניאון, LCD, מינימלי, שקיעה
- חלון מעוגל צף (דסקטופ מסביב)
- גרירה · ⚙ / ✕ בריחוף על השעון · לחצן ימני · `Esc`
- הגדרות: עיצוב, 12/24, שניות, תאריך, תמיד מעל

## הרצה

```
yod.exe הרץ "פרוייקט דוגמה\שעון"
```
