תעבוד מול התוכנות החופשיות (יוד מוניטור, יוד גיבוי, וכל תוכנה עתידית).

## פריסה (deploy)

מעלים את **תוכן** התיקייה כמו שהוא לשרת, כך שיהיה נגיש בכתובות:

```
https://servxx.com/ads/ads.json
https://servxx.com/ads/monitor.png
https://servxx.com/ads/backup.png
https://servxx.com/ads/servxx-dev.png
https://servxx.com/ads/servxx-web.png
```

דרישות:

- **HTTPS** (התוכנות מושכות דרך WebView2 + בקשת HTTP של יוד).
- ה-`Content-Type` של התמונות `image/png` ושל המניפסט `application/json` (רוב השרתים עושים זאת אוטומטית).

## איך זה עובד מול התוכנות

- כל תוכנה חופשית קוראת ל-`אתחל_פרסום(באנר)` (ראו `פרוייקט דוגמה/עיצוב/פרסום.יוד`).
- הכתובת שנטענת מוגדרת בקבוע `כתובת_שרת_פרסום` = `https://servxx.com/ads/ads.json`.
- התוכנה מושכת את `ads.json` בבקשה **אסינכרונית** (לא חוסמת), מציגה את הפרסומת הראשונה,
  ומתחלפת **כל 5 דקות**. בלי אינטרנט הרצועה מקופלת ומנסה שוב כל ~30 שנ'.
- קליק על הכרזה פותח את שדה `קישור` בדפדפן המערכת.

## עריכה / הוספת פרסומת

עורכים את `ads.json` בלבד (אין צורך לעדכן את התוכנות):

```json
{
  "מרווח_דקות": 5,
  "פרסומות": [
    { "תמונה": "https://servxx.com/ads/monitor.png", "קישור": "https://servxx.com/monitor", "כותרת": "יוד מוניטור" }
  ]
}
```

- `מרווח_דקות` — אופציונלי; גובר על ברירת המחדל (5).
- `תמונה` — URL מלא לתמונה (רצועה רוחבית 63px, רוחב 100%, `object-fit:cover`).
- `קישור` — לאן הקליק מוביל.
- `כותרת` — טקסט חלופי / tooltip.

מומלץ לתמונות: **רצועה רחבה ונמוכה (לידרבורד)** ביחס ~16:1 עד 20:1
(הבאנרים כאן ~2000×120). הרצועה בתוכנה בגובה **63px** ורוחב 100%, והתמונה
מוצגת עם `object-fit: cover` — לכן כדאי לשמור את התוכן (טקסט/לוגו) בשורה מרכזית
עם מרווח מעל ומתחת, והרקע אחיד אנכית כדי שהמילוי לרוחב מלא ייראה נקי.
