# יוד (Yod) — שפת תכנות בעברית

**יוד** היא שפת תכנות מודרנית בעברית: תחביר מימין־לשמאל, עשרות ספריות מובנות,
עורך IDE עצמאי בסגנון VS Code, מכונה וירטואלית, ומודל ריצה א־סינכרוני שלא מקפיא ממשק.
בעזרתה כתבנו כבר תוכנות שולחן עבודה שלמות — ראו [תוכנות מוכנות](#תוכנות-מוכנות-חינם).

גרסה נוכחית: **0.99.1**

## תוכנות מוכנות (חינם)

תוכנות שולחן עבודה שלמות שנכתבו **כולן בשפת יוד**, מופצות בחינם (נתמכות בבאנר פרסום):

| תוכנה | תיאור | הורדה |
|-------|--------|--------|
| **[יוד מוניטור](פרוייקט%20דוגמה/מוניטור/README.md)** | ניטור אתרים/שרתים HTTP, התראות מייל, מגש מערכת, יומן 24ש׳ | [⬇️ מוניטור.zip](https://servxx.com/ads/מוניטור.zip) |
| **[יוד גיבוי](פרוייקט%20דוגמה/גיבוי/README.md)** | גיבוי וסנכרון קבצים, FTP/FTPS, יומן חי עם פסי התקדמות, ריצה ברקע | [⬇️ גיבוי.zip](https://servxx.com/ads/גיבוי.zip) |

חלצו את ה־ZIP והריצו את קובץ ה־EXE (Windows 10/11 עם WebView2).

## דוגמה פתוחת קוד — מנהל מטלות

רוצים לראות איך בונים אפליקציית שולחן עבודה שלמה ביוד? [`פרוייקט דוגמה/מטלות/`](פרוייקט%20דוגמה/מטלות/)
היא אפליקציית **מנהל מטלות** קטנה שכל הקוד שלה פתוח: ממשק ב־WebView (ספריית העיצוב עם `רשת_נתונים`
מבוססת Tabulator), אחסון ב־SQLite עם שאילתות מפורמטרות, מתג נושא כהה/בהיר ופס התקדמות חי.

```
yod.exe הרץ "פרוייקט דוגמה\מטלות"
```

## התקנה ובנייה

### אפשרות א׳ — הורדה מוכנה (Windows)

ב־[Releases](https://github.com/ycohen888/Yod-language-programming/releases) הורידו את
**`yod-*-windows-amd64.zip`** (לא רק את ה־`.exe` הבודד).
הגרסה האחרונה: **v0.99.1** (ראו [דף ה־Releases](https://github.com/ycohen888/Yod-language-programming/releases)).

1. חלצו את **כל** התיקייה (כולל `Yod IDE.exe` ו־`resources/`)
2. הריצו `yod.exe` — נפתח **יוד IDE** (אפליקציית Electron עצמאית; בלי Node)

> בלי `Yod IDE.exe` ליד `yod.exe` תופיע הודעה בעברית איך לבנות את העורך.

לבנייה מקומית של עורך ארוז אחרי clone:

```powershell
cd yod-ide
npm install
npm run dist
cd ..
.\yod.exe עורך
```

### אפשרות ב׳ — בנייה מקוד המקור

דרוש [Go](https://go.dev/dl/) 1.22+ ו־[Node.js](https://nodejs.org/) (לבניית העורך).

```powershell
cd yod
go build -o ..\yod.exe ./cmd/yod

cd ..\yod-ide
npm install
npm run dist
```

הרצה:

```powershell
.\yod.exe              # פותח Yod IDE.exe (ארוז) או Electron פיתוח
.\yod.exe גרסה
.\yod.exe הרץ yod\examples\רשת_http.יוד
.\yod.exe עזרה
```

## התחלה מהירה

קובץ `שלום.יוד`:

```יוד
הדפס("שלום עולם")

משתנה שם = קלט("מה שמך? ")
הדפס("היי, " + שם)
```

```powershell
.\yod.exe הרץ שלום.יוד
```

עוד דוגמאות ב־[`yod/examples/`](yod/examples/).

### פרויקט (כמה קבצים)

הקובץ הראשי הוא תמיד `התחל.יוד`. שאר הקבצים נכללים עם `כלול` / `יבא`.
מדריך: [קובץ יחיד או פרויקט](מדריך%20שפת%20יוד/עמודים/קובץ-או-פרויקט.html).

```powershell
.\yod.exe הרץ yod\examples\רשת_http.יוד
# או: פתח תיקייה בעורך → F5 מריץ את התחל.יוד
```

## יכולות מרכזיות

### שפה
- משתנים, תנאים (`אם` / `אחרת`), לולאות (`כל_עוד`, `עבור`)
- פונקציות, מחלקות, ירושה (`מרחיב`), `פרטי` / `ציבורי`
- `נסה` / `תפוס` / `זרוק`, `בחר` / `מקרה`
- מתודות עשירות על מחרוזת, מספר, רשימה ומילון
- הרצה במפרש או במכונה וירטואלית (`הרץ --מכונה`)
- סגנון רשמי כמו PHP: `()` לתנאים ופרמטרים, `{}` לבלוקים (גם `סוף` עדיין נתמך)
- **א־סינכרוני בלי קפיאות**: `משימה` / `המתן` עם נעילת ריצה גלובלית (GIL),
  ופעולות רשת/מייל/הקלטה עם ידיות אסינכרוניות שלא מקפיאות את הממשק

### ספריות מובנות (`כלול "..."`)
| ספרייה | תפקיד |
|--------|--------|
| `בסיס` | הדפס, קלט, המרות, אקראי… |
| `קבצים` | קריאה/כתיבה, העתקה, ארכיונים |
| `JSON` | פרסור וסריאליזציה |
| `זמן` | תאריך, חותמת, פרסור, הפרשים |
| `מתמטיקה` | פי, סינוס, חזקה… |
| `מערכת` | סביבה, זיכרון, תהליכים, כוננים |
| `רשת` | HTTP בעברית + שרת, FTP/FTPS/SFTP, WebSocket (סינכרוני + אסינכרוני) |
| `SQL` | SQLite, MySQL, PostgreSQL |
| `חלונות` | GUI ל־Windows: חלון, מגש מערכת, WebView, טבלה, גרף, GPU |
| `גרפים` | עמודות, קו, עוגה מקצועיים |
| `ציור` | לוח, צורות, שמירת תמונות (כולל טקסט דו־כיווני) |
| `GPU` | OpenGL מקומי: סצנה, glTF, נכסים |
| `הצפנה` | Base64, MD5, SHA-256, HMAC |
| `לוח` / `עכבר` / `מקלדת` | clipboard, מיקום/לחיצות, מקשים (Windows) |
| `מספרים` | פסיקים, כסף, בתים, אחוזים לתצוגה |
| `גיליון` | Excel xlsx — תאים, סגנון, גרפים |
| `אימייל` | SMTP/Gmail/HTML + IMAP + OAuth (סינכרוני + אסינכרוני) |
| `חומרה` | Serial/COM ב־Windows |
| `אוטומציה` | עכבר/מקלדת/קיצורים/חלונות/צילום מסך |
| `הקלטה` | הקלטת מסך (FFmpeg) עם טקסט על הווידאו |
| `תרגום` | לוקליזציה (`ט(...)`, קבצי `.po`/`.mo`), זיהוי שפת מערכת |

### עורך יוד (חדש — `yod-ide/`)
- Electron + React + CodeMirror 6, ממשק כהה בסגנון VS Code
- אריזה עם **electron-builder** → `Yod IDE.exe` עצמאי (`npm run dist`)
- RTL מלא לעברית, צביעת תחביר PHP Dark+
- סייר קבצים, ניתוח קובץ, סמלי פרויקט
- F12 / Ctrl+לחיצה להגדרה, Shift+F12 להפניות, Ctrl+P / Ctrl+Shift+F
- F5 הרצה · F6 מכונה · F7 בדיקה (סימוני gutter)
- `יוד סדר` / Shift+Alt+F לסידור קוד
- איקון יוד ב־EXE, בחלון ובפס המשימות

פרטים: [`yod-ide/README.md`](yod-ide/README.md).

### אריזה
```powershell
.\yod.exe ארוז תוכנית.יוד
```
