עורך יוד (IDE)

מגרסה 0.77 העורך הראשי הוא יוד IDE — Electron + Monaco בסגנון Visual Studio Code: סייר, טאבים מהירים, פלטת פקודות, מינימפה, פאנל בעיות/פלט, והרצה דרך yod.exe.

הפעלה

yod
yod עורך
yod עורך נתיב\לפרויקט

בפעם הראשונה יש לבנות את ה־IDE: 

cd yod-ide
npm install
npm run build

קיצורים

קיצורפעולה
Ctrl+Shift+Pפלטת פקודות
Ctrl+Oפתיחת קובץ
Ctrl+Sשמירה
Ctrl+Nקובץ חדש
F5הרצה
F6מכונה
F7בדיקה

ביצועים

  • טעינת קבצים אסינכרונית (main process)
  • מעבר טאבים = החלפת מודל Monaco בלי טעינה מחדש
  • הדגשת תחביר ב־web worker

עורך Win32 הישן

אם צריך את העורך הקודם: 

set YOD_LEGACY_EDITOR=1
yod עורך
