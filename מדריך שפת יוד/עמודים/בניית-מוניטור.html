בניית מוניטור אתרים — מרשימת URL עד חלון חי

מדריך לבניית אפליקציית ניטור HTTP בשפת יוד — על בסיס פרוייקט דוגמה/מוניטור/. הרבה כתובות, לכל אחת מרווח והגדרות משלה, ממשק ימין/שמאל, ותמיכה ב־he/en/fr.

איך להשתמש: בנו לפי הסדר (מודל → בדיקה מדורגת → UI → תרגום). השוו לקוד בפרויקט אחרי כל שלב.

1. מה בונים

  • רשימת אתרים עם שם, URL, מרווח בדיקה, זמן־קצוב וסף כשלונות.
  • ניטור אוטומטי לפי מרווח פר־אתר (לא מרווח גלובלי אחד).
  • תור בדיקה מדורג — כדי ש־רשת.גש החוסם לא יקפיא את החלון.
  • פריסה לפי שפה: עברית RTL (רשימה מימין); אנגלית/צרפתית LTR.
  • תפריט עליון + תרגום ממשק (עברית / English / Français).
  • מדריך משתמש מתוך עזרה → מדריך (נארז עם ה־EXE); אודות כולל servxx.com.
  • מגש מערכת (X מסתיר לרקע) + הפעלה עם Windows.
  • מייל תקלה והחלמה, סף איטיות ms, היסטוריה 24ש׳, ייצוא JSON וייבוא ממזג (בלי דריסה).

5. מנוע בדיקה מדורג

רשת.גש חוסם — לכן יש תור מזהים: טיק רקע (~1 שנ׳) בודק מי «הגיע זמנו», מכניס לתור, ובכל צעד בודקים אתר אחד בלבד.

הצלחה = קוד HTTP בטווח 2xx/3xx בלבד (200–399). 4xx/5xx נחשבים שגיאה ומעלים את מונה הכשלונות הרצופים.

אחרי סף כשלונות רצופים — טוסט התראה, ומייל HTML פעם אחת (רק אם השליחה הצליחה; אם המייל כבוי — לוג ביומן והדגל לא ננעל). כשהאתר חוזר לתקין מתאפסים הכשלונות ו־מייל_נשלח.

6. ממשק — ימין / שמאל

  • דשבורד (פריט ראשון בתפריט): סיכום כל הבדיקות, תגי סטטוס, רשימת אתרים ויומן
  • סרגל עליון: דשבורד · קובץ · בדיקה · תצוגה · שפה · עזרה (מדריך + אודות עם servxx.com)
  • מימין (צד): תצוגת_עץ של כתובות + הוסף
  • משמאל (ראשי): דשבורד / לשוניות הגדרות־אתר / בדיקה / יומן / הגדרות תוכנה

ב־עברית (RTL) העמודה הראשונה בשורת המכל מופיעה מימין — זו הרשימה. באנגלית/צרפתית הכיוון מתהפך ל־LTR דרך עיצוב_קבע_כיוון (כולל אזור הגלילה הראשי).

7. תרגום he / en / fr

  • כלול "תרגום" + קבצים ב־תרגומים/ (לא תרגום/ — התנגשות בשם)
  • עטיפה ט(מפתח) → תרגום.ט
  • אחרי החלפת שפה: רענון תפריט ותוויות; שמות/כתובות של המשתמש לא מתורגמים

8. הגדרות תוכנה ודיווח מייל

מתפריט קובץ → הגדרות תוכנה (או תצוגה) נפתח עמוד כללי:

  • שפת ממשק וערכת נושא (כהה / בהיר)
  • הגדרות מייל: Gmail (סיסמת אפליקציה או OAuth) או SMTP חיצוני
  • רשימת נמענים לדיווח תקלות

כשאתר מגיע לסף הכשלונות הרצופים, נשלח מייל HTML מעוצב פעם אחת עד שהאתר חוזר לתקין (2xx/3xx). כשהאתר מתאושש אחרי דיווח תקלה — נשלח מייל החלמה (אם מופעל). סף סף_latency_ms מעל 0 מסמן סטטוס «איטי» ונספר ככשל להתראה. תוכן המייל בשפת הממשק (עברית RTL / en·fr LTR). ההעדפות נשמרות ב־נתונים/העדפות.json; היסטוריית בדיקות ב־נתונים/היסטוריה.json; יומן הפעילות (24 שעות) ב־נתונים/יומן.json ונשאר אחרי סגירה/פתיחה.

X בחלון מסתיר למגש המערכת; יציאה אמיתית מ־«יציאה» בתפריט/מגש. Checkbox «הפעלה עם Windows» רושם את האפליקציה ב־Run של המשתמש. קובץ → ייצא שומר JSON של האתרים; ייבא ממזג לפי כתובת — מוסיף רק אתרים שלא קיימים (בלי לדרוס).

9. רשימת בדיקה

  1. הוסיפו 3+ כתובות עם מרווחים שונים — כל אחת נבדקת לפי שלה
  2. בחירה מימין מרעננת את הפאנל משמאל
  3. אתר שמחזיר 403/404 מסומן כשגיאה; אחרי סף כשלונות — מייל אחד (אם מופעל)
  4. אתר שנשאר שבור — אין מייל נוסף; אחרי התאוששות ל־200 וכשל שוב — מייל חדש
  5. מייל כבוי + כשל — לוג «מייל כבוי» ביומן; אחרי הפעלה נשלח דיווח
  6. שמירה חוזרת אחרי הפעלה מחדש (אתרים + יומן 24ש׳)
  7. «בדוק הכל» רץ מדורג בלי להקפיא
  8. החלפת שפה ל־en/fr וחזרה ל־he (RTL)
  9. יוד בדוק התחל.יוד — נקי
