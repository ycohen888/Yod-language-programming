ספריית מערכת

ארגומנטי שורת פקודה, משתני סביבה, תיקיית עבודה, יציאה מבוקרת — ומידע ממערכת ההפעלה: זיכרון, מעבד, שם מחשב, IP ועוד. טוענים עם כלול "מערכת".

פונקציות — תהליך וסביבה

פונקציהתיאור
מערכת.ארגומנטים()רשימת ארגומנטים אחרי שם הקובץ
מערכת.סביבה(שם)ערך משתנה סביבה (מחרוזת; ריקה אם לא קיים)
מערכת.תיקייה()נתיב תיקיית העבודה הנוכחית (cwd)
מערכת.תיקיית_הרצה()תיקיית הפרויקט / ה־EXE (0.98.13) — מומלץ למשאבים באריזה
מערכת.שנה_תיקייה(נתיב)משנה את תיקיית העבודה
מערכת.צא([קוד])מסיים את התוכנית; ברירת מחדל קוד 0
מערכת.הוסף_להפעלה(שם [, פקודה])רישום ל־Run של Windows (HKCU); ברירת פקודה = ה־EXE הנוכחי
מערכת.הסר_מהפעלה(שם)מסיר את הרישום
מערכת.רשום_בהפעלה(שם)אמת אם קיים ב־Run
מערכת.הפעל(פקודה, [ארגומנטים…])מריץ תהליך ומחזיר מילון: קוד, פלט, שגיאה
מערכת.הפעל_ברקע(פקודה, …)מפעיל בלי לחכות לסיום

פונקציות — מידע מערכת הפעלה

פונקציהתיאור
מערכת.שם_מחשב()שם המחשב ברשת (hostname)
מערכת.מערכת_הפעלה()סוג מערכת: Windows / Linux / macOS
מערכת.גרסת_הפעלה()גרסה מפורטת (למשל Windows 11 Pro + מספר build)
מערכת.ארכיטקטורה()ארכיטקטורת מעבד (amd64, arm64…)
מערכת.ליבות()מספר ליבות לוגיות
מערכת.מעבד()מילון: שם, ליבות, ארכיטקטורה
מערכת.זיכרון()מילון: סהכ_מגה, פנוי_מגה, בשימוש_מגה, אחוז (+ גרסאות בבתים)
מערכת.שימוש_מעבד()אחוז שימוש כולל במעבד (0–100)
מערכת.זמן_פעיל()שניות מאז עליית המערכת
מערכת.כוננים()רשימת כוננים: אות, סהכ_מגה, פנוי_מגה, בשימוש_מגה
מערכת.תהליכים()רשימת תהליכים (ממוינת לפי זיכרון): מזהה, שם, נתיב, זיכרון_מגה
מערכת.סיים_תהליך(מזהה)מסיים תהליך; מחזיר {הצלחה, שגיאה}
מערכת.איפי()רשימת כתובות IP של המחשב (בלי loopback)
מערכת.משתמש()שם המשתמש המחובר
מערכת.בית()נתיב תיקיית הבית
מערכת.מידע()מילון מרוכז (כולל מעבד, זיכרון, כוננים, זמן פעיל…)
